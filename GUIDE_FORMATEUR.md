# Guide formateur EquipIT

## Déroulé conseillé

1. Faire expliquer le modèle `Equipment` et ses états.
2. Faire repérer la frontière entre `services.py` et `views.py`.
3. Demander une démonstration des transitions emprunt / retour.
4. Vérifier les tests nominaux et les cas d'erreur.
5. Faire tester les endpoints dans Swagger UI.

## Points d'attention

Le projet reste volontairement limité : aucune authentification ni CRUD complet n'est demandé. L'évaluation porte sur la compréhension de Django, la séparation des responsabilités, la validation et les tests.
